# Glaze Script Language Support

Language support plugin for GlazeScript (`.gscript`) used in GlacialEngine.

## Features
- **Code Formatting:** Configurable brace matching, indentation, and structure formatting.
- **Completion:** Auto-completion for keywords, types, and qualifiers.
- **File Templates:** Quick creation of new `.gscript` files via the `New -> Glaze Script File` menu.

## Installation
- Install directly from the [JetBrains Marketplace](https://plugins.jetbrains.com).
- Or download the latest `.zip` release and install via `Settings -> Plugins -> ⚙️ -> Install Plugin from Disk...`.

## Building
```bash
./gradlew buildPlugin
```
